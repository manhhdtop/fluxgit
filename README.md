# FluxGit Releases

Official release repository for **FluxGit**.

This repository hosts the published installers and release notes for FluxGit. The application source code is maintained in a separate private repository.

## Download

Download the latest version from the **Releases** page:

https://gitlab.com/fluxgit/fluxgit-release/-/releases

## Available Packages

* **Windows x64** (`.exe`)

Additional platforms may be added in future releases.

## Release Notes

Each release includes:

* Version number
* Changelog
* Installation package
* Release date

## Installation

1. Download the latest Windows installer from the Releases page.
2. Run the installer.
3. Follow the installation wizard.
4. Launch **FluxGit** from the Start Menu or Desktop shortcut.

## Requirements

* Windows 10 (64-bit) or later
* Internet connection (recommended for repository hosting providers)

## Reporting Issues

If you encounter a bug or have a feature request, please contact the project maintainer or use the official support channel if one has been provided.
